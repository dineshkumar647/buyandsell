REUSE MARKET — CLASSIFIEDS BUY & SELL WEBSITE

How to run:
1. Extract this ZIP file.
2. Open the ReUseMarket folder.
3. Double-click index.html to open the home page in Chrome/Edge/Firefox.

Separate sections/pages:
- index.html — Home page
- buy.html — Buy Products page (browse/search/filter products and view seller contact details)
- sell.html — Sell Products page (add a used product listing)

Features:
- Sample used products in multiple categories.
- Search products by name, description or category.
- Filter by category and sort by price or recently added.
- Separate Buy Products and Sell Products pages.
- Seller form: product name, category, price, condition, description, seller name, phone and optional image URL.
- New listings are saved in browser LocalStorage and appear on the Buy Products page.
- Responsive layout for mobile and desktop.

Important:
This is a front-end college project. Listings are stored only in the same browser using LocalStorage.
It does not have real user accounts, server/database syncing, real chat, secure payments or delivery.
Seller contact details for sample products are demo data. For a real marketplace, add a backend,
database, authentication and safe contact/payment workflows.
